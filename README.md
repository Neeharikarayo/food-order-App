
## 🍔 Food Order App
A simple and interactive Food Ordering Web Application built using HTML, CSS, and JavaScript. This project allows users to browse food items, add them to a cart, and view the total price dynamically.

## 📌 Features
🛒 Add and remove items from the cart

🍕 Browse different food items

💰 Dynamic total price calculation

📱 Responsive design (works on mobile & desktop)

⚡ Smooth and interactive user experience
---
## 🛠️ Tech Stack

HTML – Structure of the application

CSS – Styling and layout

JavaScript – Functionality and interactivity
